## Demo

1. Open the lesson and check the evidence question. A named plugin and “no plugins” are unsupported.
2. Keep the original neutral frames and cue; Apply storyboard. A places the cue on beat 2; B on beat 3.
3. Advance four times. Compare the marked frame and cue in both versions. Return to beginning.
4. Change the cue beat to 4 and apply: B wraps to beat 1. Explain how that changes anticipation, without an expected emotional answer.
5. Add a short reflection. Inspect/copy or download JSON. Check that `source.verification` remains `pending`.
6. Keep a manual next-step note in Creator OS. Study JSON is not a PIXIE/Creator Session import. Upload no source media automatically. Roomy and MCP are not connected.

## Export and privacy

`tarantula-visual-study/v1` stores four bounded frame descriptions, original cue, cue beat and optional reflection; includes an unverified source reference and rights-review notice. No identities, timestamps of user behavior, device IDs, scores, recordings or credentials are collected. User text is rendered with `textContent`, not HTML. No import, executable chart data, fetch, local storage or autoplay. Download is explicit; copyable JSON remains available. Publishing is a separate human choice. The application cannot establish authorship or clearance.

## Validation boundary

Node tests cover cue placement, unchanged frames, bounds, explicit wrap and pending-source export. Browser testing covers the original default and changed cue, evidence feedback and readable preview. These tests do not verify the source footage, physical devices, real-time sync, rights, iPad or VoiceOver. No changes to Duet, Inpatient, MIDI behavior or Creator OS data schemas.
