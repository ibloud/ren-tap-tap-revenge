# Rhythm & Remedy — Provenance and Prototype Boundary

> **Status:** Fan-made prototype. No Ren music license is granted by this repository.

## Purpose

This repository demonstrates a rhythm-game interaction model using the music and artistic identity of Ren as its subject.

The prototype's code and mechanics are separate from Ren's music rights. A code license does not license a recording, composition, lyrics, performance, name, likeness, or artwork.

## What may be prototyped without assuming music rights

Contributors can develop and test the interaction model with:

- placeholder audio;
- original/cleared audio;
- synthetic tones;
- creator-owned rhythm charts;
- timing data created from authorized source material.

The prototype should not package or redistribute an unlicensed Ren recording merely because the game is noncommercial or fan-made.

## Future charting / MIDI work

A chart, MIDI, transcription, beat map, or timing representation should have its own provenance record.

For each source, record:

- source track/version;
- source authority;
- who created the chart;
- whether the source was authorized for charting;
- whether the chart may be redistributed;
- required credit;
- any restrictions on edits or derivative representations.

Do not treat a chart as proof that the underlying recording or composition has been licensed.

## Participation and attribution

Ren is the subject/artist referenced by this fan prototype. That does not establish participation, endorsement, ownership, or approval.

Use explicit states:

- **Reference**
- **Proposed**
- **Awaiting confirmation**
- **Active**
- **Licensed**
- **Closed**

A public profile or streaming page is evidence for identification/discovery, not proof of licensing authority.

## Definition of done for a rights-safe prototype

- [ ] Mechanics work with placeholder/cleared audio.
- [ ] Source and contributor records exist for charts/timing data.
- [ ] No unlicensed master is packaged for distribution.
- [ ] Artist attribution is factual and non-endorsing.
- [ ] Any future music use has a separate written rights record.

**Principle:** Make the prototype reusable without making the artist's rights invisible.
